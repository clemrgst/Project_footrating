# AI Audit

Real errors made by the AI assistant that we caught. Every entry describes an error we
actually observed; none is invented. Target: at least 4 entries, at least one per team member.

## Entry template

Copy this block for each new entry, numbered in order.

```markdown
## Error N — <short title>

- **Date:** YYYY-MM-DD
- **Caught by:** Clément / Paul
- **Module:** M1 / M2 / M3 / M4 / project-wide
- **AI error:** what the AI said or did wrong (quote it if possible).
- **How we detected it:** the check, command, page or test that showed the error.
- **Impact:** what would have happened if we had kept it (wrong number, leakage, licence issue…).
- **Correction:** what we changed.
- **Commit:** <hash or PR link of the fix>
```
